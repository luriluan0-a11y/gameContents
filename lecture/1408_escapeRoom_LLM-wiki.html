1개요

가족 단위 참가자가 AI(바이브코딩)의 도움을 받아 수수께끼를 풀어 방을 탈출하는 웹 게임을 직접 기획하고, 그 기획서를 AI IDE(Antigravity)에 넣어 실제 동작하는 HTML 게임으로 완성하는 특강 세션입니다. 코딩 경험이 없는 참가자도 "기획서 작성기" 웹앱에서 항목만 채우면 자동으로 마크다운 기획서가 만들어지고, 이를 AI에게 그대로 전달해 게임을 생성하는 흐름입니다.

2오늘의 목표

  • 수수께끼를 풀어 방을 탈출하는 방탈출 게임을 만든다.
  • 방 안에 숨겨진 힌트를 찾고, 문제를 풀어야만 다음 문으로 나갈 수 있게 설계한다.
  • AI의 도움을 받아 나만의 방탈출 이야기와 수수께끼를 직접 설계해본다.

3방탈출 특화 설계 규칙

  1. 한 곳에 오래 머물러야 하는 장르 특성상 방의 분위기가 다소 왜곡되어(과장되어) 있는 경향이 있다.
  2. 방 안에 움직이는 오브젝트를 배치해 힌트를 얻을 수 있도록 한다.
  3. 수수께끼·퍼즐 요소를 넣어 풀이 자체의 재미를 살린다.

6전체 제작 흐름 (참가자 관점)

  1. 배경 사진 고르기 — 정신병원 / 장난감의 방 / 귀신의 저택 / 미래 저택 / 해적의 방 / 감옥 중 선택.
  2. 기획서 작성기(escapeRoom_paper.html)에서 예시를 참고해 기획서 작성.
  3. 완성되면 마크다운 파일 다운로드.
  4. Antigravity IDE를 열고 "마크다운 파일을 읽고 html 단일 페이지로 개발해줘." 라고 요청.
  5. 완성된 html 파일을 열어 직접 플레이해본다.

이 흐름은 1408_escapeRoom_guide.html의 "이렇게 만들어요!" 섹션과 정확히 대응됩니다.

7기획서 작성기(escapeRoom_paper.html) 상세

바닐라 HTML/CSS/JS(프레임워크 없음, 단일 파일)로 만든 폼 기반 도구입니다.

주요 기능

  • 예시대로 채우기 / 초기화 버튼: 글쓰기가 막막한 사용자를 위해 원클릭으로 전체 예시 데이터를 채우거나, 전체 입력을 리셋.
  • 배경 사진 선택: 6장의 썸네일 그리드. 클릭 시 라이트박스로 확대, "이걸로 선택" 버튼으로 1장 선택(선택 시 배지·테두리 강조).
  • 기본 정보: 게임 제목, 시놉시스(플레이어가 왜 탈출해야 하는지).
  • 오브젝트/퍼즐 목록: "+ 오브젝트 추가" 버튼으로 블록을 동적으로 추가/삭제. 각 블록은 오브젝트 이름, 종류(대화 | 퍼즐), 내용(대사 또는 퍼즐 규칙·정답)을 입력. 종류를 바꾸면 라벨/placeholder가 즉시 바뀜.
  • 엔딩 문구, Game Over 문구 + 재도전 버튼 여부.
  • 마크다운 다운로드: 입력값을 조합해 # 게임 기획서 형식의 .md를 Blob으로 생성, <a download>로 파일명은 게임 제목(특수문자 제거) 기준 자동 생성.

생성되는 마크다운의 고정 지시문

다운로드되는 마크다운 맨 위에는 항상 다음 지시문이 주석(//)으로 포함되어, AI IDE가 구현 방식을 오해하지 않도록 못박아 둡니다.

//게임의 구현 방법은 사용자가 선택한 이미지 위에 오브젝트 이미지를 생성하고,
그 생성된 이미지를 배경에 배치한 후에 오브젝트를 클릭해서 구동되는 방식이야.
사용자가 추가한 오브젝트의 개수 만큼 이미지를 생성하고 배경에 띄운 후
클릭 시 동작하도록 구현해줘.

즉 "배경 이미지 위에 오브젝트를 핫스팟으로 올리고, 클릭 이벤트로 대화/퍼즐을 실행"하는 구현 패턴을 AI에게 강제하는 프롬프트 역할을 겸합니다.

8예시 기획서 & 완성 게임: "왕으로부터의 탈주"

escapeRoom_paper.html의 "예시대로 채우기"로 생성된 기획서(왕으로부터의 탈주.md)를 AI가 그대로 구현한 결과물이 왕으로부터의 탈주.html입니다.

기획 내용

  • 배경: 감옥 (underground_prison_escape_bg.png)
  • 시놉시스: 삐에로 주인공이 왕을 웃기지 못해 투옥되었고, 연인 프랑소와즈를 위해 탈출해야 함.
#오브젝트종류내용
1고양이대화클릭 시 대사만 출력: "야아옹~ 나도 이 곳을 나가고 싶다."
2짝 맞추기 게임퍼즐카드 4장을 뒤집어 짝을 맞추는 메모리 게임. 틀리면 Game Over, 맞추면 비밀번호 획득
3자물쇠퍼즐2번에서 얻은 비밀번호를 입력해 열면 탈출 성공
  • 엔딩: "퍼즐을 다 풀고 방을 탈출해 주인공은 프랑소와즈와 만나 행복하게 살았습니다."
  • Game Over: "방을 탈출하지 못했습니다. 다시 도전하세요." + 재도전 버튼 있음

구현 구조 (왕으로부터의 탈주.html)

단일 HTML 파일, 프레임워크 없이 순수 JS로 구현되어 있습니다.

  • #scene: 배경 이미지를 background-image로 깐 16:9 무대. 그 위에 .hotspot 버튼 3개를 left/top 퍼센트 좌표로 절대배치(고양이 16%/70%, 카드게임 50%/58%, 자물쇠 83%/60%). 각 핫스팟 아이콘은 bob 키프레임으로 위아래로 까딱까딱 움직여 "힌트가 있는 오브젝트"임을 시각적으로 드러냅니다(설계 규칙 2번 구현).
  • 오브젝트 클릭 분기(data-obj 속성으로 구분):
    • cat → 대사 오버레이(openCat)만 표시.
    • cards → 짝 맞추기 미니게임(setupCardGame/onCardClick) 오버레이. 셔플(shuffle), 두 장 비교, 실패 시 gameOverOverlay 오픈, 성공 시(onCardGameWin) state.passwordKnown = true로 전환하고 해당 핫스팟에 solved 클래스(발광 효과) 부여.
    • lock → 4자리 숫자 입력(#lockInput). passwordKnown이 false면 아직 비밀번호를 모른다는 에러 메시지, true면 입력값과 SECRET_CODE 비교 후 일치 시 엔딩 오버레이, 불일치 시 흔들림 애니메이션 + 에러 메시지.
  • 상태 관리: 전역 state 객체(passwordKnown 등)로 퍼즐 간 의존관계(카드 게임을 풀어야 자물쇠를 열 수 있음)를 표현 — 기획서의 "퍼즐 2 → 퍼즐 3" 순차 구조가 그대로 코드에 반영됨.
  • 오버레이 시스템: .overlay 공통 스타일 + openOverlay/closeOverlay 헬퍼로 대화창, 퍼즐창, 엔딩창, Game Over창을 동일한 패턴으로 처리.
  • 재도전: restartGame()이 passwordKnown을 초기화하고 solved 클래스를 제거해 카드 게임부터 다시 시작 가능.

9안내 페이지 (1408_escapeRoom_guide.html)

특강 당일 화면에 띄워두는 진행용 랜딩 페이지입니다. 섹션 구성은 위 2~6번 내용과 1:1로 대응되며, 각 섹션에 앵커(#goal, #videos, #rules, #paper, #steps)를 두어 상단 네비게이션에서 바로 이동 가능합니다. 기획서 작성기 링크(escapeRoom_paper.html)로 연결되는 CTA 버튼이 중간과 하단 두 곳에 배치되어 있습니다.

10이 워크숍의 핵심 아이디어 (재사용 포인트)

"기획서 작성 웹앱 → 마크다운 다운로드 → AI IDE에 붙여넣기 → 코드 자동 생성" 패턴은 비개발자가 AI로 완성된 웹앱을 만들게 하는 재사용 가능한 특강 템플릿입니다.
  • 마크다운 안에 구현 방식을 못박는 주석 지시문을 심어두면, 어떤 AI 도구에 붙여넣어도 일관된 구조(배경+핫스팟+클릭 이벤트)로 구현되도록 유도할 수 있다.
  • "예시대로 채우기" 버튼처럼 최소 하나의 완성 예시를 원클릭으로 체험하게 하면, 빈 화면에 압도되는 초보 참가자의 진입장벽을 크게 낮춘다.
