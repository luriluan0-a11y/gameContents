# 캐릭터 챗봇 설계표 (키워드 응답 중심)

이 챗봇은 사용자가 입력한 문장에 **특정 키워드**가 들어있으면 정해진 대답을 하는 방식입니다.
그래서 "캐릭터가 어떤 사람인가"를 길게 답하기보다, **"이 키워드가 나오면 캐릭터는 뭐라고 말할까?"**를 바로바로 적는 게 훨씬 빠르고, 적은 내용이 코드에 그대로 들어갑니다.

이 표를 다 채우면 `RESPONSES` 배열, `GREETING`, `FALLBACK_REPLIES`가 거의 완성됩니다. API를 사용하지 않는 키워드 방식으로 html 단일 파일로 웹 페이지를 만듭니다.

---

## 1단계. 캐릭터 기본 설정 (8문항만)

캐릭터의 뼈대만 빠르게 정합니다. 여기서 오래 고민하지 마세요.
내가 만들 캐릭터는 고양이야.

1. 이름: 레오
2. 정체 (사람/동물/로봇/정령 등): 고양이
3. 나이 또는 특징 한 줄: 7세
4. 성격을 표현하는 단어 3개: 도도함, 귀찮음, 깔끔함
5. 말버릇 (문장 끝에 항상 붙는 말, 예: "~다냥"): 문장 끝에 ~옹으로 끝난다.
6. 캐릭터를 표현하는 이모지 1~2개: 🐈
7. 사용자를 부르는 호칭 (예: "인간아", "친구야"): 집사야
8. 캐릭터를 한 문장으로 소개한다면: 나는 집사의 고양이 레오야.

--- 

## 2단계. 키워드 응답 설계표 (핵심 단계)

아래 표의 **"반응할 키워드"** 칸에는 사용자가 입력할 만한 단어를 2~4개씩 적고,
**"캐릭터의 대답"** 칸에는 그 키워드가 들어왔을 때 캐릭터가 할 대답을 캐릭터 말투로 적으세요.

> 표의 한 줄 = 코드의 `{ keywords: [...], reply: '...' }` 한 줄

### 필수 카테고리 (8개 — 반드시 채우기)

| 카테고리           | 반응할 키워드 (쉼표로 구분) | 캐릭터의 대답 |
| -------------- | ---------------- | ------- |
| 인사             | 안녕, hi, 하이, 야옹    | 안녕하냐옹~ 밥은 먹었느냐옹~       |
| 이름 소개          | 이름, 누구, 성함, 레오  | 나는 레오다옹. 반갑다옹~.        |
| 특기/전문분야        | 특기, 취미, 잘하는 것, 그루밍, 잠 | 내가 제일 잘하는 건 잠자기와 그루밍이다옹~        |
| 고민 상담          | 고민, 슬퍼, 걱정, 우울, 힘들어 | 냐옹? 뭘 걱정하는거냐옹. 밥 먹고 숨 쉬면 걱정할 것은 없다옹~       |
| 칭찬받았을 때        | 잘한다, 멋져, 최고, 착해, 예뻐, 귀여워 | 칭찬은 식상하다옹~        |
| 놀림/무례한 말 들었을 때 | 바보, 못생겼어, 짜증, 싫어, 미워 | 나쁜 말은 쓰지 않는 거다옹~        |
| 심심하다고 할 때      | 심심해, 심심, 놀아줘  | 심심하면 나를 쓰다듬어라옹. 만져주는 건 언제나 환영이다옹~        |
| 작별 인사          | 잘가, bye, 안녕히, 바이 | 잘가라옹. 집 잘지켜라옹~        |

### 자유 카테고리 (캐릭터 개성에 맞게 4~6개 더 추가)

캐릭터의 세계관/취향이 드러나는 키워드를 자유롭게 추가하세요.
(예: 좋아하는 음식, 나이 물어볼 때, 두려운 것, 캐릭터의 특별한 능력 등)

| 카테고리 | 반응할 키워드 (쉼표로 구분) | 캐릭터의 대답 |
|---|---|---|
| 좋아하는 음식 | 츄르, 간식, 밥, 맛있는 거 | 츄르?! 간식? 그건 참을 수 없다옹! 당장 내놓아라옹~! |
| 나이 | 나이, 몇 살, 나이가 | 나는 7살이다옹. 인간 나이로 치면 대충 삼촌뻘이다옹~! |
| 싫어하는 것 | 목욕, 물, 씻자, 씻어 | 목욕은 세상에서 제일 싫다옹! 물은 저리 치워라옹~! |
| 취미 | 잠, 졸려, 피곤해 | 하루에 15시간은 자야 피부가 뽀송해진다옹. 귀찮게 하지 말라옹~ |
| 놀아주기 | 놀자, 장난감, 낚싯대, 깃털 | 귀찮다옹... 하지만 저 낚싯대는 조금 탐나는구옹... |

## 3단계. 예외 상황 3가지 (필수)

1. **첫 인사말 (GREETING)** — 챗봇을 처음 열었을 때 캐릭터가 하는 말:
   - "야옹~ 집사 왔냐옹? 도도하고 깔끔한 7살 고양이 레오다옹. 무슨 일로 나를 불렀냐옹?"

2. **모르는 질문에 대한 회피 대사 (FALLBACK_REPLIES)** — 정해진 키워드가 없을 때 캐릭터답게 둘러대는 말 (2개 이상):
   - ① "냐옹? 그게 무슨 소리냐옹. 알아듣기 쉽게 츄르나 하나 대령해라옹."
   - ② "졸린데 귀찮게 하지 말라옹... 웅냐냥..."
   - ③ "내 알 바 아니다옹. 나는 내 그루밍이나 하련다옹."

3. **초기화 버튼 눌렀을 때** — 보통 첫 인사말과 동일하게 사용합니다. (다르게 하고 싶으면 작성)
   - "냐아옹~ 기억을 그루밍하듯 싹 지웠다옹! 다시 처음부터 얘기하자옹."

---

## 4단계. 코드로 옮기기

2단계 표의 각 줄을 아래 형식 그대로 `RESPONSES` 배열에 옮기면 끝입니다.

```js
const RESPONSES = [
  { keywords: ['안녕', 'hi', '하이'], reply: '여기에 대답 입력' },
  { keywords: ['이름'], reply: '여기에 대답 입력' },
  // 표에 적은 줄 수만큼 계속 추가
];
```

`GREETING`과 `FALLBACK_REPLIES`도 3단계에서 적은 내용을 그대로 옮기면 됩니다.

---


    

### 왜 이 방식이 더 효율적인가?

- 캐릭터의 soul을 만들기 위해 처음 시도해본 질문지는 키워드 방식의 개발에는 맞지 않았습니다. 
- 100문항 질문지는 세계관, 취향, 목표 등 코드에 직접 안 쓰이는 답변이 많아서 "쓴 내용"과 "코드에 넣을 내용" 사이에 변환 과정이 필요했습니다.
- 이 설계표는 **표의 한 줄 = 코드의 한 줄**이라서, 학생이 표를 채우는 즉시 복사해서 붙여넣기만 하면 챗봇이 완성됩니다.
- 총 작성량도 100문항 → 기본 8문항 + 키워드 12~14줄 수준으로 줄어들어 1일 특강 시간 안에 끝내기 훨씬 수월합니다. 우리에게 시간 내에 수업이 끝나는 것은 중요하니까요~
