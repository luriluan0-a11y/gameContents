# 경조사 안내 페이지 만들기

한국폴리텍대학 성남캠퍼스
2026.08.13

- AI를 활용하는 데 가장 유용한 것은 자주 반복하는 일을 AI에게 시키는 것임(지난 시간과 같은 원칙)
- 결혼식 청첩장, 돌잔치, 부고 안내처럼 살면서 반복적으로 마주치는 "경조사 안내"를 오늘 AI로 직접 만들어봄

1. 지난 시간(8/10) 뉴스레터 복습
2. 경조사 안내 페이지가 무엇인지, 어떤 종류가 있는지 확인
3. 우리 경조사 정보(주인공, 일시, 장소, 연락처 등) 정리
4. AI에게 초안 요청
5. 모바일 한 페이지 html로 변환
6. 계좌번호 등 민감정보 노출 범위 점검
7. 카카오톡·문자로 실제 공유까지 실습

## 지난 시간 복습

- 8/10에 뉴스레터를 기획 → 프롬프트 → 표 기반 html 변환 → 발행까지 진행함
- 오늘은 형식만 다를 뿐 같은 흐름(기획 → 프롬프트 → html 변환 → 공유)을 경조사 안내 페이지에 적용함

## 경조사 안내 페이지란?

- 결혼식, 돌잔치·백일잔치, 회갑·칠순·팔순잔치, 부고, 개업·이전처럼 인생의 중요한 순간을 알리는 모바일 한 페이지임
- 업체에 맡기지 않고 직접 만들면 비용을 아낄 수 있고, 내용도 원하는 대로 자유롭게 수정할 수 있음
- 카카오톡·문자로 링크 하나만 보내면 돼서 전달이 빠르고 편함

세 가지 예시

- **결혼식 청첩장**: 신랑신부 소개, 예식 일시·장소, 갤러리, 참석 여부 응답(선택)
- **돌잔치·회갑/칠순잔치**: 주인공 소개, 행사 일시·장소, 오시는 길
- **부고 안내**: 고인 소개, 발인·장지 안내, 조의금 계좌(선택), 근조화환 안내

## 기획하기

정해야 할 것

- **경조사 종류**: 결혼식 / 돌잔치 / 회갑·칠순·팔순 / 부고 / 개업·이전 등
- **주인공 정보**: 이름, 관계(신랑신부, 상주 등)
- **톤앤매너**: 정중하고 차분한 존댓말로 통일

개인정보 주의사항

- 계좌번호·전화번호 등 민감정보는 꼭 필요한 경우에만 넣기
- 검색엔진에 노출되는 공개 채널에는 올리지 않고, 카카오톡·문자 등으로 직접 전달하기

## 필수 정보 체크

**공통 정보**
- 주인공 이름과 관계
- 일시(날짜, 시간)
- 장소(이름, 주소, 지도 링크)
- 연락처(문의받을 사람)

**경조사별 추가 정보**
- 결혼식: 혼주 이름, 계좌번호(마음 전하실 곳), 식사 안내
- 돌잔치·칠순 등: 화환 안내, 주차 안내
- 부고: 발인 일시, 장지, 상주 이름, 조의금 계좌

## 프롬프트 예시 (2단계로 진행)

한 번에 다 시키지 않고, 먼저 정보를 마크다운으로 정리한 뒤 그걸 바탕으로 html을 요청함

**STEP 1 — 정보를 마크다운 파일로 정리 요청**

//아래 내용 복사할 수 있도록 만들어줘
~~~
경조사 종류: (예: 결혼식 청첩장 / 돌잔치 초대장 / 부고 안내)
주인공: (이름, 관계)
필수 정보: 일시, 장소(주소+지도링크), 연락처, 계좌번호(선택)
톤앤매너: 정중하고 차분한 존댓말로 통일해주세요.
위 내용을 정리해서 마크다운 파일로 만들어주세요.
~~~

**STEP 2 — 마크다운을 바탕으로 html 변환 요청**

//아래 내용 복사할 수 있도록 만들어줘
~~~
방금 만든 마크다운 파일을 바탕으로 경조사 안내 페이지를 만들어주세요.
디자인: 형광색은 사용하지 말아주세요. 모바일 화면에 최적화해서 만들어주세요.
공유 방식: 카카오톡, 문자로 링크를 보낼 예정이라 단일 html 파일로 만들어주세요.
~~~

## 개인정보 주의사항

- 계좌번호를 올릴 때는 받는 사람 이름을 함께 정확히 표기하기 (사칭·사기 피해 예방)
- 완성한 페이지는 검색엔진에 노출되지 않는 비공개 링크로 카카오톡·문자를 통해 직접 전달하기
- 부고 안내는 고인 정보나 가족 연락처를 꼭 필요한 범위만 공개하기

## 배포·공유해보기

- 완성한 페이지를 지난 시간에 배운 방법(깃허브 페이지, Vercel 등)으로 호스팅
- 링크를 카카오톡 단체방·개인 메시지, 문자로 공유
- 원하면 QR코드로 만들어서 청첩장 실물에 인쇄해도 됨(선택)
