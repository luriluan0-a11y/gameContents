# 개념 소개

제네릭이 왜 필요한지, 어떤 문제를 해결하는지 알아봅니다.

제네릭 없이 (문제점)
✗  Before — object 사용
public class Box
{
    public object Value { get; set; }
}

var box = new Box();
box.Value = 42;         // 박싱 비용!

// 런타임 오류 위험
string s = (string)box.Value;
// InvalidCastException ↑
✓  After — 제네릭 사용
public class Box<T>
{
    public T Value { get; set; }
}

var box = new Box<int>();
box.Value = 42;         // 박싱 없음

// 컴파일 타임 타입 검사
int n = box.Value;       // ✓ 안전
제네릭의 세 가지 핵심 장점
🛡

타입 안전성

잘못된 타입 사용 시 런타임이 아닌 컴파일 타임에 오류를 발견합니다. 예외 없이 안전합니다.

♻

코드 재사용

하나의 클래스·메서드로 int, string, 사용자 정의 타입 등 모든 타입을 처리합니다.

⚡

성능 향상

값 타입의 박싱·언박싱이 제거됩니다. 메모리 할당과 GC 부담이 크게 줄어듭니다.

💡 타입 매개변수 관례 단일 타입은 T, 키-값 쌍은 TKey / TValue, 입출력은 TIn / TOut, 요소는 TElement로 명명하는 것이 C# 관례입니다.

# 문법과 선언

제네릭 클래스, 메서드, 인터페이스를 선언하는 방법입니다.

제네릭 클래스
Repository.cs C# 
public class Repository<T>
{
    private readonly List<T> _items = new();

    public void Add(T item)            => _items.Add(item);
    public T    Get(int index)          => _items[index];
    public int  Count()                  => _items.Count;
    public IEnumerable<T> GetAll()     => _items;
}

// 사용 — 타입 인수를 꺾쇠괄호로 지정
var repo = new Repository<string>();
repo.Add("홍길동");
repo.Add("이순신");
string first = repo.Get(0); // "홍길동"
제네릭 메서드
Utils.cs C# 
public static T Max<T>(T a, T b)
    where T : IComparable<T>
{
    return a.CompareTo(b) >= 0 ? a : b;
}

// 컴파일러가 T를 자동으로 추론 (타입 추론)
int    m1 = Max(3, 7);               // T = int    → 7
string m2 = Max("apple", "mango");   // T = string → "mango"
double m3 = Max(3.14, 2.71);          // T = double → 3.14
다중 타입 매개변수
Pair.cs C# 
public class Pair<TFirst, TSecond>
{
    public TFirst  First  { get; }
    public TSecond Second { get; }

    public Pair(TFirst first, TSecond second)
        => (First, Second) = (first, second);

    public override string ToString()
        => $"({First}, {Second})";
}

var p1 = new Pair<string, int>("나이", 25);    // (나이, 25)
var p2 = new Pair<bool, double>(true, 3.14);  // (True, 3.14)
✓ 타입 추론 (Type Inference) 메서드 호출 시 인수의 타입으로 T를 추론할 수 있으면 꺾쇠괄호를 생략할 수 있습니다. 클래스 인스턴스 생성에는 적용되지 않으므로 반드시 명시해야 합니다.

# 제약 조건

where 키워드로 타입 매개변수가 만족해야 할 조건을 지정합니다.

제약 조건 종류
제약 조건 설명 비고
where T : class T는 참조 타입이어야 합니다. (class, interface, delegate, array) null 허용
where T : struct T는 값 타입이어야 합니다. (int, bool, struct 등) Nullable 제외
where T : new() T는 매개변수 없는 기본 생성자를 가져야 합니다. new T() 호출이 가능해집니다. 항상 마지막
where T : BaseClass T는 지정한 클래스를 상속해야 합니다. 해당 클래스의 멤버 사용이 가능해집니다. 단일 클래스
where T : IFoo T는 지정한 인터페이스를 구현해야 합니다. 여러 인터페이스를 쉼표로 나열할 수 있습니다. 다중 가능
where T : notnull T는 null을 허용하지 않는 타입이어야 합니다. (C# 8.0+) C# 8.0+
복합 제약 조건
Shelter.cs C# 
// T는 Animal을 상속하고, IComparable을 구현하며, 기본 생성자가 있어야 함
public class Shelter<T>
    where T : Animal, IComparable<T>, new()
{
    private List<T> _residents = new();

    public T CreateAndAdopt()
    {
        T animal = new T();  // new() 제약 덕분에 가능
        animal.Feed();        // Animal 멤버 사용 가능
        _residents.Add(animal);
        return animal;
    }

    public T FindSmallest()
    {
        _residents.Sort();  // IComparable 덕분에 가능
        return _residents[0];
    }
}

# 제네릭 컬렉션

System.Collections.Generic 네임스페이스의 주요 컬렉션 클래스들입니다.

📦 using System.Collections.Generic; 모든 제네릭 컬렉션을 사용하려면 이 네임스페이스를 추가해야 합니다. .NET 6+의 global using 설정에는 이미 포함되어 있습니다.
List<T> 동적 배열
인덱스 접근 O(1), 검색·정렬 지원. 가장 범용적인 컬렉션.
var nums = new List<int> { 1, 2, 3 };
nums.Add(4);
nums.Remove(2);
nums.Sort();
int n = nums[0];
Dictionary<TKey, TValue> 해시맵
키-값 쌍 저장. 조회·추가·삭제 평균 O(1) 성능.
var map = new Dictionary<string, int>();
map["apple"] = 3;
if (map.TryGetValue("apple", out int v))
    Console.WriteLine(v); // 3
Queue<T> FIFO
선입선출. 작업 대기열, BFS 탐색 등에 사용.
var q = new Queue<string>();
q.Enqueue("first");
q.Enqueue("second");
string s = q.Dequeue(); // "first"
Stack<T> LIFO
후입선출. 실행 취소, DFS 탐색, 괄호 검사 등에 사용.
var stack = new Stack<int>();
stack.Push(10);
stack.Push(20);
int top = stack.Pop(); // 20
HashSet<T> 집합
중복 없는 집합. 합집합·교집합·차집합 연산 지원.
var a = new HashSet<int> { 1, 2, 3 };
var b = new HashSet<int> { 2, 3, 4 };
a.IntersectWith(b); // {2, 3}
a.UnionWith(b);     // {1,2,3,4}
LinkedList<T> 연결 리스트
노드 기반 이중 연결 리스트. 삽입·삭제 O(1), 인덱스 접근 없음.
var ll = new LinkedList<string>();
ll.AddFirst("A");
ll.AddLast("B");
ll.AddAfter(ll.First, "X");
✓ 선택 기준 순서 있는 데이터 → List<T>  |  키로 찾기 → Dictionary<TKey,TValue>  |  중복 제거 → HashSet<T>  |  작업 대기열 → Queue<T>  |  되돌리기 → Stack<T>

제네릭 인터페이스 구현
ITransformer.cs C# 
public interface ITransformer<TIn, TOut>
{
    TOut Transform(TIn input);
}

public class StringToInt : ITransformer<string, int>
{
    public int Transform(string input) => int.Parse(input);
}

public class IntToString : ITransformer<int, string>
{
    public string Transform(int input) => input.ToString("D4");
}

ITransformer<string, int> t1 = new StringToInt();
int result = t1.Transform("42"); // 42

ITransformer<int, string> t2 = new IntToString();
string s = t2.Transform(7); // "0007"
제네릭 + LINQ 조합
LinqExtensions.cs C# 
// 사용자 정의 제네릭 필터 — yield return으로 지연 실행
public static IEnumerable<T> Filter<T>(
    IEnumerable<T> source,
    Func<T, bool> predicate)
{
    foreach (var item in source)
        if (predicate(item)) yield return item;
}

// 제네릭 변환 메서드
public static IEnumerable<TResult> Map<TSource, TResult>(
    IEnumerable<TSource> source,
    Func<TSource, TResult> selector)
{
    foreach (var item in source)
        yield return selector(item);
}

// 활용
var evens  = Filter(new[] { 1,2,3,4,5 }, n => n % 2 == 0);  // [2, 4]
var labels = Map(new[] { 1,2,3 }, n => $"#{n}");              // ["#1","#2","#3"]
✓ 핵심 정리 제네릭은 C#에서 타입 안전성·성능·재사용성을 동시에 얻는 가장 강력한 도구입니다. List<T>와 Dictionary<TKey,TValue>는 이미 제네릭으로 만들어진 표준 라이브러리이며, 직접 제네릭 클래스·메서드를 설계하면 중복 없는 우아한 코드를 작성할 수 있습니다.
