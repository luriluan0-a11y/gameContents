📚 수업에서 배운 내용 총정리

옵시디언 study 폴더에 기록된 수업 자료와 학습 내용을 종합적으로 요약한 문서입니다.

🌐 1. 웹 개발 기초

인라인 스타일 (Inline Style)

  • 개념: HTML 태그 안에 직접 style="..." 속성을 넣어 디자인을 적용하는 방식입니다. (마치 글자에 직접 스티커를 붙이는 것과 같습니다.)
  • 장점: 딱 하나의 요소를 빠르고 직관적으로 변경할 때 매우 편리합니다.
  • 단점: 스타일이 많아지면 코드가 복잡해지고 일괄 수정이 어려워집니다.
  • 예시: <p style="color: red;">안녕하세요</p>

파닉스 단어 학습 앱 (웹 애플리케이션 구조)

  • 단어 학습(플립 카드)과 퀴즈 기능이 결합된 싱글 페이지 애플리케이션(SPA)의 구조를 배웠습니다.
  • TTS 음성 재생: window.speechSynthesis (Web Speech API)를 활용하여 단어를 직접 발음해주는 기능 구현.
  • 상태 관리: 학습 진행도, 점수 계산 등의 상태(State)를 JavaScript 변수로 관리하는 로직을 배웠습니다.

🤖 2. AI 및 프롬프트 엔지니어링

프롬프트 토큰 효율성

  • 현상: AI에게 존댓말이나 장황한 인삿말을 사용하면 한국어 처리 특성상 토큰 소모량이 2~3배 이상 증가합니다.
  • 해결책: 불필요한 서술어를 줄이고 개조식(Bullet points)이나 명사형/반말 위주의 간결한 핵심 요구사항으로 프롬프트를 작성합니다.
  • AI는 감정이 없으므로 명확한 맥락 전달이 가장 중요합니다.

옵시디언 & 마크다운의 AI 호환성

  • 마크다운(Markdown): 불필요한 태그와 스타일 노이즈가 없는 순수 텍스트(Plain Text)라 LLM이 가장 빠르고 정확하게 읽어낼 수 있는 데이터 구조입니다.
  • 옵시디언(Obsidian): 백링크([[문서]])와 태그(#태그)로 문서를 연결하여 AI에게 풍부한 맥락(Context)을 제공합니다. RAG(검색 증강 생성)에 최적화된 환경입니다.
  • 데이터 소유권: 클라우드 종속 없이 내 컴퓨터 로컬에 완전 소유 가능합니다.
