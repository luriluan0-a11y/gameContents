🪟 Windows 필수 단축키 가이드

작업 속도와 생산성을 2배로 올려주는 핵심 단축키 모음

📋

자주 쓰는 필수 단축키

  • 복사
    Ctrl + C
  • 붙여넣기
    Ctrl + V
  • 잘라내기
    Ctrl + X
  • 실행 취소 (이전 작업으로)
    Ctrl + Z
  • 다시 실행 (취소한 작업 되돌리기)
    Ctrl + Y
  • 전체 선택
    Ctrl + A
  • 찾기 (단어/문자열 검색)
    Ctrl + F
🚀

생산성 윈도우 키 (Win)

  • 파일 탐색기 열기
    Win + E
  • 바탕화면 바로 가기
    Win + D
  • 클립보드 기록 열기
    Win + V
  • 화면 캡처 (영역 지정)
    Win + Shift + S
  • 화면 잠금 (자리 비울 때)
    Win + L
  • 작업 보기 (가상 바탕화면)
    Win + Tab
  • 이모지 / 특수문자 창
    Win + .
🖥️

창 관리 및 화면 분할

  • 창 좌/우 반할 정렬
    Win + ← / →
  • 창 최대화 / 최소화
    Win + ↑ / ↓
  • 실행 중인 창 전환
    Alt + Tab
  • 현재 창 닫기 / 종료
    Alt + F4
🌐

웹 브라우저 & 시스템

  • 작업 관리자 열기
    Ctrl + Shift + Esc
  • 브라우저 새 탭 열기
    Ctrl + T
  • 현재 탭/창 닫기
    Ctrl + W
  • 닫은 탭 다시 열기
    Ctrl + Shift + T

💡 강력 추천하는 핵심 팁

Win + V (클립보드 기록) 기능은 꼭 활성화해 보세요! 이전에 복사해 두었던 여러 개의 텍스트나 이미지를 목록에서 골라 자유롭게 붙여넣을 수 있어 작업 시간을 크게 단축해 줍니다.
