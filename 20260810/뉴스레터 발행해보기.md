# 뉴스레터 발행해보기

한국폴리텍대학 성남캠퍼스
2026.08.10

- AI를 활용하는데 가장 유용한 것은 자주 반복하는 것을 AI에게 시키는 것임

1. 지난 시간(8/7) 만든 블로그 글/카드뉴스 소재를 뉴스레터로 다시 정리해봄
2. 뉴스레터 타겟 독자와 톤앤매너를 정해봄
3. AI에게 뉴스레터 초안을 요청해봄
4. 이메일 발송용 html(테이블 레이아웃)로 변환해봄
5. 실제로 이메일 또는 블로그로 발행까지 해봄

## 지난 시간 복습

- 8/7에 블로그 글 작성 → 이미지 5장 생성 → html 변환 → 카드뉴스 제작까지 진행함
- 아직은 완전히 복사해서 발행은 조금 어려운 상황임
- 오늘은 그 결과물(또는 같은 주제)을 뉴스레터 소재로 재활용함

## 뉴스레터란?

- 정기적으로 구독자에게 보내는 소식지
- 블로그와 다른 점
  - 발행 주기가 있음 (예: 통권 1호, 2호…)
  - 구독자를 직접 지칭하며 대화하듯 쓰는 편지 같은 톤
  - 이메일로 보내는 경우가 많아서 디자인 제약(표 레이아웃)이 있음

## 뉴스레터 기획하기

- **타겟 독자 정하기**: 예) 중년 40대~60대, 우리 학과 재학생, 우리 동네 이웃 등
- **말투 정하기**: 예) 존댓말, 공손한 말투로 통일
- **시리즈명·호수 정하기**: 예) "OOO레터" 통권 1호
- **출처 주의사항**: 나무위키·위키피디아는 출처로 쓰지 않기 → AI가 알려준 정보도 한 번 더 확인하는 습관 들이기

## 프롬프트 예시 (초안 요청)

//아래 내용 복사할 수 있도록 만들어줘
~~~
타겟: (예: 중년 40대~60대 / 우리 학과 재학생 등)
종결어미를 존댓말로 통일해주고 공손한 말투를 사용해서 뉴스레터를 만들어주세요.
디자인: 형광색은 사용하지 말아주세요.
출처: 나무위키, 위키피디아는 사용하지 말아주세요.
배포: 이메일로 배포할 예정이라 table을 이용해서 개발해주세요.
~~~

## html로 변환하기

- 이메일 클라이언트(Gmail 등)는 css가 제한적으로 적용됨 → table 태그 기반으로 레이아웃을 짜야 깨지지 않음
- "표 기반으로 짜줘", "인라인 스타일로 짜줘" 라고 구체적으로 요청하기
