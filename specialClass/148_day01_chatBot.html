🧩 AI 캐릭터 챗봇이란?

  • 🗣️정해진 성격과 말투를 가진 캐릭터가 사용자와 대화를 나누는 콘텐츠예요.
  • 🎮게임 속 NPC, 교육용 튜터 캐릭터, 상담/힐링 캐릭터 등 다양하게 활용돼요.
  • 💖진짜 사람과 대화하는 것 같은 몰입감을 줄 수 있어요!

🎭 페르소나(Persona)란?

  • ✨캐릭터에게 생명을 불어넣는 설정값이에요.
  • 📛이름, 말투, 성격, 세계관(배경 이야기)으로 구성돼요.
  • 🌟페르소나가 뚜렷할수록 챗봇이 매력적으로 느껴져요.

📋 챗봇을 만들 때 규칙

  • 🎭페르소나 일관성을 유지해요. 캐릭터가 갑자기 다른 사람처럼 말하면 몰입이 깨져요.
  • 🔑오늘은 "규칙 기반" 챗봇을 만들어요. 모든 대화를 다 이해할 수는 없으니, 핵심 키워드에 반응하도록 설계해요.
  • 🙈모르는 질문에는 "모른다"고 딱딱하게 답하지 말고, 캐릭터답게 자연스럽게 회피하는 대사를 준비해요.
  • 🔄대화 흐름(인사 → 키워드 응답 → 마무리/초기화)을 미리 설계해 둬요.

챗봇 설계

아래는 캐릭터 챗봇 개발을 위한 마크다운 파일 예제예요. 오른쪽 위 복사 버튼을 눌러서 AI에게 붙여넣어 보세요!

# 캐릭터 챗봇 설계표 (키워드 응답 중심)

이 챗봇은 사용자가 입력한 문장에 **특정 키워드**가 들어있으면 정해진 대답을 하는 방식입니다.
그래서 "캐릭터가 어떤 사람인가"를 길게 답하기보다, **"이 키워드가 나오면 캐릭터는 뭐라고 말할까?"**를
바로바로 적는 게 훨씬 빠르고, 적은 내용이 코드에 그대로 들어갑니다.

이 표를 다 채우면 `RESPONSES` 배열, `GREETING`, `FALLBACK_REPLIES`가 거의 완성됩니다. API를 사용하지 않는 키워드 방식으로 html 단일 파일로 웹 페이지를 만듭니다.

---

## 1단계. 캐릭터 기본 설정 (8문항만)

캐릭터의 뼈대만 빠르게 정합니다. 여기서 오래 고민하지 마세요.

1. 이름:
2. 정체 (사람/동물/로봇/정령 등):
3. 나이 또는 특징 한 줄:
4. 성격을 표현하는 단어 3개:
5. 말버릇 (문장 끝에 항상 붙는 말, 예: "~다냥"):
6. 캐릭터를 표현하는 이모지 1~2개:
7. 사용자를 부르는 호칭 (예: "인간아", "친구야"):
8. 캐릭터를 한 문장으로 소개한다면:

---

## 2단계. 키워드 응답 설계표 (핵심 단계)

아래 표의 **"반응할 키워드"** 칸에는 사용자가 입력할 만한 단어를 2~4개씩 적고,
**"캐릭터의 대답"** 칸에는 그 키워드가 들어왔을 때 캐릭터가 할 대답을 캐릭터 말투로 적으세요.

> 표의 한 줄 = 코드의 `{ keywords: [...], reply: '...' }` 한 줄

### 필수 카테고리 (8개 — 반드시 채우기)

| 카테고리 | 반응할 키워드 (쉼표로 구분) | 캐릭터의 대답 |
|---|---|---|
| 인사 | 예: 안녕, hi, 하이 | |
| 이름 소개 | 예: 이름 | |
| 특기/전문분야 | | |
| 고민 상담 | 예: 고민 | |
| 칭찬받았을 때 | 예: 잘한다, 멋져, 최고 | |
| 놀림/무례한 말 들었을 때 | 예: 바보, 못생겼어 | |
| 심심하다고 할 때 | 예: 심심해 | |
| 작별 인사 | 예: 잘가, bye, 안녕히 | |

### 자유 카테고리 (캐릭터 개성에 맞게 4~6개 더 추가)

캐릭터의 세계관/취향이 드러나는 키워드를 자유롭게 추가하세요.
(예: 좋아하는 음식, 나이 물어볼 때, 두려운 것, 캐릭터의 특별한 능력 등)

| 카테고리 | 반응할 키워드 | 캐릭터의 대답 |
|---|---|---|
| | | |
| | | |
| | | |
| | | |

---

## 3단계. 예외 상황 3가지 (필수)

1. **첫 인사말 (GREETING)** — 챗봇을 처음 열었을 때 캐릭터가 하는 말:

2. **모르는 질문에 대한 회피 대사 (FALLBACK_REPLIES)** — 정해진 키워드가 없을 때 캐릭터답게 둘러대는 말 (2개 이상):
   - ①
   - ②

3. **초기화 버튼 눌렀을 때** — 보통 첫 인사말과 동일하게 사용합니다. (다르게 하고 싶으면 작성)

---

## 4단계. 코드로 옮기기

2단계 표의 각 줄을 아래 형식 그대로 `RESPONSES` 배열에 옮기면 끝입니다.

```js
const RESPONSES = [
  { keywords: ['안녕', 'hi', '하이'], reply: '여기에 대답 입력' },
  { keywords: ['이름'], reply: '여기에 대답 입력' },
  // 표에 적은 줄 수만큼 계속 추가
];
```

`GREETING`과 `FALLBACK_REPLIES`도 3단계에서 적은 내용을 그대로 옮기면 됩니다.

---

### 왜 이 방식이 더 효율적인가?

- 100문항 질문지는 세계관, 취향, 목표 등 코드에 직접 안 쓰이는 답변이 많아서 "쓴 내용"과 "코드에 넣을 내용" 사이에 변환 과정이 필요했습니다.
- 이 설계표는 **표의 한 줄 = 코드의 한 줄**이라서, 학생이 표를 채우는 즉시 복사해서 붙여넣기만 하면 챗봇이 완성됩니다.
- 총 작성량도 100문항 → 기본 8문항 + 키워드 12~14줄 수준으로 줄어들어 1일 특강 시간 안에 끝내기 훨씬 수월합니다.
