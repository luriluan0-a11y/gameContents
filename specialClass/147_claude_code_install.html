GitHub 계정 만들기

홈페이지를 공유·배포하는 데 필요합니다.

  1. github.com 접속
  2. Sign up 클릭
  3. Continue with Google 클릭 → 본인 Google 계정으로 로그인
  4. 이메일 인증 완료
2

Claude 계정 & Pro 구독

Claude Code를 사용하기 위해 필요합니다.

결제는 매달 합니다. 다른 생성형 AI를 사용해야 할 수도 있으니 절대 연결제 금지! (저는 했어요. ㅋ)
  1. claude.ai 접속
  2. 계정 생성 후 Pro 구독 ($20/월)
3

VS Code 설치

집에서는 Cursor, Antigravity 등 쓰셔도 됩니다. 강의실에는 깔려 있을 겁니다. 확인!!!

  1. code.visualstudio.com 접속
  2. 본인 OS(Windows) 버전 다운로드
  3. 다운로드된 파일 실행 → 설치
4

Claude Extension 설치 (쉬운 방법!)

VS Code 안에서 채팅 패널로 Claude를 쓰는 방법입니다. 클릭 몇 번이면 끝!!!

  1. VS Code 왼쪽 사이드바에서 Extensions 아이콘 클릭 (네모 3개 모양)
  1. 검색창에 Claude 입력
  2. Anthropic 제작 확인 후 Install 클릭
5

Extension 열기

  1. 왼쪽 사이드바 첫 번째 파일 아이콘 눌러서 파일 목록 다시 열기
  2. Claude 익스텐션 패널 열기:
    • 우측 상단 클로드 모양 주황색 아이콘 누르기
    • 또는 단축키: Ctrl + Shift + Esc (Windows)
6

로그인 & 테스트

  1. Sign In 버튼 클릭
  2. 브라우저에서 Claude 계정 로그인 → 허용 클릭
  3. Claude 패널에 "안녕하세요" 입력 → 응답 오면 성공!
여기까지 진행해도 Claude Code를 사용할 수 있습니다. 이제 터미널 버전 설치입니다.
Extension만으로는 안 되는 고급 기능(MCP 연결, 자동화 스크립트 등)을 위해 필요합니다.
7

GIT 설치

  1. git-scm.com/download/win 접속
  2. 64-bit Git for Windows Setup 클릭
  3. 다운로드된 .exe 파일 실행 → 모든 옵션 기본값 그대로 두고 Next → 설치 완료

VS Code 터미널에서 설치 확인:

git --version
설치 후 VS Code를 완전히 종료했다가 다시 열어야 git 명령어가 인식됩니다.
8

Claude Code 설치 (터미널 버전)

자동화에 필요하지만, 코드 짤 때도 편해요.

  1. VS Code 상단 메뉴에서 Terminal → New Terminal 클릭
    단축키: Ctrl + ` (백틱, 숫자 1 왼쪽 키)
  2. 아래 명령어를 터미널에 붙여넣기 → Enter:
irm https://claude.ai/install.ps1 | iex
CMD(명령 프롬프트)에서는 작동하지 않습니다. 반드시 PowerShell을 사용하세요.
  1. VS Code 완전히 종료 후 다시 열기
  2. 터미널에서 확인: claude --version 입력 → 버전 나오면 성공!
9

PATH 설정 (안 되면 필수)

claude 명령어가 안 되는 경우 아래 설정을 해주세요.

  1. Win + R 누르고 → sysdm.cpl 입력 → Enter → 고급 탭 클릭
  2. "환경 변수" 버튼 클릭
  3. 사용자 변수에서 Path 선택 → 편집 클릭
  4. 새로 만들기 → 아래 2개를 각각 추가:
%USERPROFILE%\.local\bin
%USERPROFILE%\.claude\bin
  1. 확인 → VS Code 완전히 종료 후 다시 열기
  2. 터미널에서 claude --version 다시 확인
10

Claude Code 로그인 (터미널용)

터미널에서 claude를 직접 사용하기 위한 로그인입니다. Extension 로그인과 별개입니다.

  1. VS Code 상단 메뉴에서 Terminal → New Terminal 클릭 (Ctrl + `)
  2. claude 입력 → Enter
  3. 테마 선택 → Light 또는 Dark 선택 (아무거나 OK, 하지만 개발자라면 Dark지.)
  1. 로그인 방법 → Claude account with subscription 선택
  1. 브라우저가 자동으로 열림 → Claude 계정으로 로그인 → 허용 클릭
  2. 터미널로 돌아와서 "안녕하세요" 입력 → 응답 오면 터미널 설정도 완료!
!
