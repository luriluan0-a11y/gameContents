교육용 게임이란?

오늘 만들어볼 게임 — 간단한 학습 앱!

📌 교육용 게임의 특징
  • 목적이 명확하다!
  • 교육 효과가 있다면 재미가 좀 없어도 괜찮다???
  • 재미도 있으면 더 좋겠지요!
🎯 진지한 게임 (Serious Game)

교육, 훈련, 의료, 국방 등 특정 목적을 달성하기 위해 설계된 기능성 게임을 말합니다.
단순한 오락을 넘어 실질적인 학습 효과를 목표로 합니다.

🎲 게임을 만들 때 지켜야 할 규칙
1
학습에 꼭 필요한 요소에는 "노.가.다"가 있다.
반복 학습은 필수! 지루하지 않게 설계하는 것이 핵심입니다.
2
재미있게 반복할 수 있다면 — 확실한 피드백과 보상을 설계하기
점수, 이펙트, 격려 메시지 등으로 학습 동기를 유지시키세요.
3
틀렸다고 바로 "The End"를 주지 말기!
"다시 해봐~" → 다시 도전할 수 있도록 구현하세요.
4
제목은 직관적으로, 학부모도 타겟이 되어야 한다.
교육용 콘텐츠의 구매 결정자는 학부모! 제목과 설명을 명확하게 쓰세요.

교육용 게임 설계

AI에게 전달할 프롬프트 예제 — 버튼을 눌러 복사하세요!

📋 프롬프트 예제
나는 교육용 콘텐츠를 개발하는 개발자이고, 너는 나를 가르쳐주는 프로그램 선생님이야. 중학교 학생의 난이도로 영어 단어를 학습하는 앱을 만들고 싶어 문제는 총 100개. 문제를 풀 때마다 1점씩 증가하고, 총점을 기록해주면 좋겠어. 데이터는 배열로 저장해서 내가 편집할 수 있었으면 좋겠어. 첫 번째 페이지는 "중학생을 위한 영어 마스터"라고 나오고 하단에 "Start"라는 버튼을 클릭하면 다음 페이지부터 영어 학습이 가능해. 문제를 맞추면 "참 잘했어요." 라는 피드백과 함께 이펙트가 터지도록 만들어주고, 틀리면 틀렸다고 하지 말고 "다시 한 번 풀어봐."라고 피드백을 해줘. 문제를 풀다가 이전, 다음으로 이동할 수 있고, home으로 이동하는 버튼도 만들어줘. 중학생들이 좋아할 만한 디자인으로 만들어주면 좋겠어. html 단일 페이지로 만들어줘.
💡
"html 단일 페이지로 만들어줘" — 이 요청이 핵심입니다!
하나의 HTML 파일 안에 모든 기능을 담을 수 있어 배포와 공유가 매우 편리합니다.
🌐

웹 앱 개발 기초

기본적으로 3개의 파일이 필요합니다

.html index.html

사용자에게 보이는 화면(Front)의 구조를 정의하는 태그들이 담긴 파일

.css style.css

사용자에게 보이는 화면의 디자인을 기록한 파일

.js script.js

사용자에게 보이는 화면의 동작을 구현해놓은 파일

3개
"교육용 앱 만들어줘"

html · css · js 각각 분리된 3개 파일 생성

1개
"단일 파일로 만들어줘"

모든 코드가 담긴 html 파일 1개만 생성
