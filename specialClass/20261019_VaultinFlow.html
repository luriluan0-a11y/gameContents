사례 B · 1저장 위치도 맡기기

AI가 내가 정해 둔 위키 규칙을 지켰습니다

실제로 보낸 요청
PARA 비슷한 번호 체계라는 내용이 뭔지 정리를 좀 해주면 좋겠어.
어디에 저장할지는 내 볼트를 검토해서 기록해주면 될 것 같아
이 위키는 볼트 안 원문 자료에 근거한 내용만 쓰는 규칙이 있습니다. 볼트에 PARA 원문 자료가 없으므로 위키 대신 개인 공부 노트 폴더에 저장하겠습니다.Claude Code의 답

주제로만 보면 AI 지식관리 위키가 맞는 자리였지만, AI는 위키의 규칙 문서를 먼저 읽었습니다. 출처 없는 내용이 지식 페이지에 섞이지 않게 하려고 만든 규칙이 처음으로 작동하는 걸 봤습니다.

자동화가 쓰는 파일은 언제 옮길까

오늘 옮기기로 했습니다. 자동화는 다른 PC에서 돌고 있어서, 그 PC의 에이전트에게 보낼 경로 변경 요청 메시지를 AI가 대신 써 줬습니다.

"보내지 않으면 내일 아침 실패 알림이 온다. 잘못된 곳에 기록되지는 않는다"는 설명 덕분에, 안 보냈을 때 어떻게 되는지도 미리 알았습니다.

AI에게 맡길 것과 내가 쥘 것

이렇게 했더니 좋았습니다

  • 요약 말고 적용을 묻기. 내 상황과의 대조표가 나오고, 하지 말아야 할 것까지 걸러집니다.
  • 판단은 내가, 재료는 AI가. 마지막 작업일·링크 영향을 뽑게 하면 결정이 몇 초 만에 끝납니다.
  • 규칙 파일을 써 두기. 저장 위치를 맡겨도 AI가 규칙을 읽고 엉뚱한 곳에 넣지 않습니다.
  • 사실과 해석을 나눠 적기. 가르칠 때 무엇을 단정해도 되는지 바로 보입니다.
  • 내 일에 먼저 적용하고 가르치기. 직접 헷갈린 지점이 퀴즈와 교수자 가이드에 들어갑니다.

이렇게 하면 안 됩니다

  • 좋은 스터디자료의 폴더 체계를 통째로 들여오기. 역할이 같은 폴더의 이름만 바꾸면 자동화와 링크만 깨집니다.
  • 파일 탐색기에서 폴더를 끌어다 옮기기. 옵시디언 밖에서 옮기면 링크가 갱신되지 않습니다.
  • AI가 정리한 개념 글을 출처 확인 없이 지식 저장소에 넣기.
  • 학생 실습에서 AI에 파일 "내용"을 넣게 하기. 이름만으로 충분합니다.
