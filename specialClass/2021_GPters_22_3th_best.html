C# 프로그래밍 — 어떤 문제가 있었나?

학생들이 무료 생성형 AI를 사용할 때,
"객체지향으로 짜줘"라고 해도 static으로만 코드를 만들어 주는 경우가 많았습니다.

  • "로또 번호 생성기 만들어줘" 한 줄로는 원하는 구조가 나오지 않음

사용한 md 프롬프트 예시

RandomNumber.cs 파일에 45개의 숫자를 랜덤하게 뽑는 프로그래밍을 구현해줘.
중복 여부를 판단하는 메소드는 따로 구현하고, 메인에서는 사용자에게 물어봐.
"로또 생성기를 사용해보시겠습니까? 1. 응 2. 아니"

md 파일을 분석해서 부족한 부분이 있으면 업데이트해줘.

파일명을 지정하는 것만으로 클래스 분리가 자연스럽게 이루어짐

RandomNumber.cs

C#
public class RandomNumber
{
    private static readonly Random _random = new Random();
    private const int MinNumber = 1, MaxNumber = 45, LottoCount = 6;

    /// 중복 없는 로또 번호 6개 생성 후 정렬 반환
    public List<int> GenerateLottoNumbers()
    {
        List<int> numbers = new List<int>();
        while (numbers.Count < LottoCount)
        {
            int candidate = _random.Next(MinNumber, MaxNumber + 1);
            if (!IsDuplicate(numbers, candidate))
                numbers.Add(candidate);
        }
        numbers.Sort();
        return numbers;
    }

    /// 중복 여부 판단 (별도 메소드 분리)
    public bool IsDuplicate(List<int> numbers, int candidate)
    {
        foreach (int n in numbers)
            if (n == candidate) return true;
        return false;
    }

    public string FormatNumbers(List<int> numbers)
        => "[" + string.Join(", ", numbers) + "]";
}

Program.cs — Main

C#
RandomNumber rn = new RandomNumber();
bool isRunning = true;

while (isRunning)
{
    Console.WriteLine("로또 생성기를 사용해보시겠습니까?\n  1. 응\n  2. 아니");
    string input = Console.ReadLine()?.Trim();

    switch (input)
    {
        case "1":
            var nums = rn.GenerateLottoNumbers();
            Console.ForegroundColor = ConsoleColor.Yellow;
            Console.WriteLine("행운의 번호: " + rn.FormatNumbers(nums));
            Console.ResetColor();
            break;

        case "2":
            Console.ForegroundColor = ConsoleColor.Cyan;
            Console.WriteLine("안녕~");
            Console.ResetColor();
            isRunning = false;
            break;

        default:
            Console.WriteLine("⚠️  1 또는 2를 입력해 주세요.");
            break;
    }
}

마크다운 응용 — 더 넓은 활용

  • 재사용성이 높고 결과가 잘 나와 실습 만족도 향상
  • 매년 반복되는 서류 → md 초안 생성 후 양식에 맞게 수정 제출
  • 강의자료도 md로 관리 → 조금씩 변경하며 재활용
  • 다른 예제·성능 개선 요청 시에도 md 패턴 그대로 적용
핵심: md로 구조화된 요구사항을 전달하면
AI가 의도를 훨씬 정확하게 이해합니다.
