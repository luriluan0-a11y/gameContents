## 📌 개념과 우리 약속

이 수업의 핵심은 모든 프롬프트를 ChatGPT 프로젝트에서 만든다는 점입니다.

- Reve에서는 프롬프트를 새로 작성하지 않고, ChatGPT에서 완성한 프롬프트를 복사해 이미지 생성만 합니다.
- Canva에서는 완성된 이미지 위에 텍스트를 올려 최종 리소스를 만듭니다.

### ✅ 체크리스트

- [ ] 스토리·캐릭터·그래픽 컨셉·페이지별 프롬프트는 모두 ChatGPT 프로젝트에서 만든다
- [ ] Reve = 이미지 생성 도구로 사용한다
- [ ] Reve 이미지에는 텍스트를 직접 생성하지 않는다
- [ ] 프롬프트에는 Canva에서 글을 올릴 여백/레이아웃 위치를 반드시 지정한다
- [ ] Canva = 텍스트 편집 및 최종 리소스 제작에 사용한다
- [ ] 표지와 뒷표지는 본문 10페이지 이후 별도로 제작한다

**한 줄 정리**: ChatGPT로 기획하고 프롬프트를 만들고 → Reve로 그림을 만들고 → Canva로 글을 올려 최종 동화책 페이지를 완성한다.

## 1. 전체 제작 흐름

| 단계 | 작업 |
|------|------|
| 1 | ChatGPT 프로젝트를 만듭니다. |
| 2 | 10페이지 이야기 구조를 정리합니다. |
| 3 | 캐릭터 설정을 정리합니다. |
| 4 | 그래픽 컨셉과 레이아웃 규칙을 정리합니다. |
| 5 | ChatGPT에서 캐릭터 레퍼런스용 프롬프트를 만듭니다. |
| 6 | Reve에서 캐릭터 Reference와 본문 이미지를 생성합니다. |
| 7 | Canva에서 텍스트를 넣고 최종 리소스를 완성합니다. |

## 2. ChatGPT 프로젝트 운영

프로젝트 1개 안에 역할별 채팅을 나누어 사용합니다.

- 👤 **캐릭터 설정 창** — 외형·의상·성격·캐릭터 레퍼런스용 프롬프트를 정리
- 🎨 **그래픽 컨셉/레이아웃 창** — 그림체·색감·조명·구도·텍스트 여백 규칙을 정리
- ✍️ **이야기 창** — 10페이지 줄거리와 페이지별 사건·감정을 정리
- 🧩 **프롬프트 제작 창** — 위 설정들을 종합해 필요한 페이지의 최종 Reve 프롬프트를 작성
- ✅ **검수 창(선택)** — 생성된 이미지의 캐릭터·색감·레이아웃 일관성을 확인

> 각 채팅창에서 정리한 내용은 작은 MD 파일처럼 프로젝트의 기준 문서로 사용합니다. 프롬프트 제작 창에서는 다른 창에서 합의한 설정을 다시 설명하지 않고, 그 내용을 기반으로 최종 프롬프트를 만듭니다.

### 프롬프트 제작 창 요청 예시

```
지금까지 만든 캐릭터 설정, 그래픽 컨셉, 이야기 구조를 바탕으로
동화책 1페이지용 Reve 프롬프트를 작성해줘.
조건:
- 16:9
- 이미지 안에는 텍스트를 넣지 않음
- Canva에서 문장을 올릴 수 있도록 왼쪽에 글 영역 확보
- 기존 캐릭터 설정과 그래픽 컨셉 유지
```
