# 마이야르 반응 숏폼 — 장면별 Reve 프롬프트

기반 문서: [[마이야르_반응_숏폼_기획안]]
용도: ChatGPT 프로젝트의 "프롬프트 제작 창"에서 완성한 프롬프트를 그대로 Reve에 붙여넣어 이미지 생성 (Reve에서 새로 프롬프트를 쓰지 않음)

공통 조건
- 비율: 9:16 세로
- 이미지 안에는 텍스트·숫자·로고를 생성하지 않는다 (자막·타이틀은 전부 Canva에서 추가)
- 각 장면 상단 또는 하단 30% 정도는 시각적으로 단순하게 비워 Canva 자막이 얹힐 여백을 확보한다
- 전 장면 공통 톤: 다큐멘터리 푸드 매크로 촬영, 어둡고 차분한 배경, 따뜻한 림 라이팅, 얕은 피사계심도, 사실적 시네마틱 룩, 채도 낮춘 색보정 — 8장면 모두 이 톤을 유지해 일관성을 지킨다
